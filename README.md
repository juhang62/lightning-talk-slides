# Lightning talk slides

Slides for a 3 to 5 minute lightning talk by Lifeng Han, Department of Mathematics, Tulane University.

The talk covers mathematical models of tumors and infections, a new result on starting populations in fitted models, a planned project on hidden drug resistance in lung cancer, and a teaching study on AI feedback in a statistics course. It ends with two requests: research collaborators, and a fishing buddy.

The PDF is attached to the latest release on this page.
